# Twitter в GasStationApp

Вкладка **Twitter** — нативный клиент существующего проекта
`/Users/kuberg/Desktop/fullsatck/react-express/twitter`.
Цвета берутся из `constants/Colors.ts`: светлая и тёмная темы совпадают с GasStationApp.
На телефоне список чатов и переписка открываются последовательно, на широком экране — рядом.

## Запуск

В GasStationApp:

```sh
nvm install
nvm use
npm install
npm start
```

Откройте приложение в Expo Go и выберите **Twitter**. Войдите в тот же аккаунт,
который используете в веб-приложении; пользователи и переписки общие.

### Локальный сервер

Запустите существующий backend Twitter (ему нужны MongoDB и его собственный `.env`):

```sh
cd /Users/kuberg/Desktop/fullsatck/react-express/twitter/backend
npm install
npm run dev
```

По умолчанию приложение берёт адрес компьютера из LAN-адреса Expo и обращается
к порту 3000. Телефон и компьютер должны быть в одной сети. В Android-эмуляторе
при отсутствии LAN-адреса используется `10.0.2.2:3000`, в iOS-симуляторе — `localhost:3000`.

### Опубликованный сервер или другой порт

На экране входа либо в списке чатов нажмите шестерёнку и задайте:

- API: тот же URL, что и `REACT_APP_API_URL` в веб-клиенте Twitter.
- WebSocket: тот же URL, что и `REACT_APP_WEBSOCKET_URL`.

Настройка сохраняется на устройстве. При смене сервера вход сбрасывается.
Для локального сервера с телефона указывайте IP компьютера, например
`http://192.168.1.10:3000` и `ws://192.168.1.10:3000`.
Expo Tunnel не публикует порт backend — при работе через туннель задайте доступный
телефону адрес API отдельно.

Можно также скопировать `.env.example` в `.env.local`, задать
`EXPO_PUBLIC_TWITTER_API_URL` и `EXPO_PUBLIC_TWITTER_WEBSOCKET_URL`, затем перезапустить
Metro. Сохранённый вручную адрес имеет приоритет над переменными окружения.
Не добавляйте в EXPO_PUBLIC-переменные JWT_SECRET или другие серверные секреты.

## Возможности

- Вход и регистрация через `/auth/login` и `/auth/registration`.
- Общий чат, личные диалоги, поиск участников и непрочитанные сообщения.
- Отправка, редактирование и удаление собственных сообщений.
- Загрузка предыдущих страниц истории, черновик каждого открытого диалога до выхода из вкладки/аккаунта.
- Удаление личной переписки у себя или у обоих с подтверждением.
- WebSocket: онлайн-статус, набор текста, изменения сообщений, статусы прочтения.
- Переподключение с задержкой и обновление через HTTP при недоступном WebSocket.
- Прочтение отмечается для видимых сообщений, когда вкладка и приложение активны.
- Токен сохраняется в Expo SecureStore на телефоне, при истечении сессии нужен повторный вход.

Нативные фоновые push-уведомления не подключены: существующий backend отправляет
Web Push для браузеров. Переписка обновляется, пока приложение открыто.

## Проверки

```sh
npm run typecheck
npm run test:twitter
npx expo export --platform android --platform ios --output-dir /tmp/gasstation-export
```

Тесты используют поддельные сетевые ответы и не отправляют сообщения реальным пользователям.
Для ручной проверки откройте общий чат на телефоне и в веб-клиенте, отправьте сообщение,
проверьте его изменение и удаление; затем проверьте личный диалог, возврат из фона и
переключение системной темы. После ошибки сети введённый текст остаётся в поле.
